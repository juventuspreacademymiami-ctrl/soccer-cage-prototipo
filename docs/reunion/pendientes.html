EasyPost paga las etiquetas de USPS desde un saldo prepagado que se recarga solo. Por transferencia bancaria (ACH) no hay comisión, pero cada recarga tarda de 3 a 5 días hábiles. Con tarjeta de crédito la recarga es inmediata, pero EasyPost cobra 3,75 % de comisión: $37,50 por cada $1.000 cargados. Por eso se recomienda el banco, con una recarga automática que arranque con saldo para varios días.
